# 跨平台采集流程

当前已实现：**公开链接 → JSON 草稿 → 人工核验 → 发布数据 → 自动生成目录**。搜索和平台读取仍需人工或有权限的外部服务；本仓库不会在后台抓取网页。

## 发现线索

同时使用通用检索词、作者清单和不断更新的模型名称补充检索。通用词示例：

- `AI video prompt`、`AI video workflow`、`prompt included`。
- `AI 视频 原始提示词`、`AI 短片 制作过程`、`视频生成 工作流`。
- 按具体平台和作者补充检索，避免只检索一个模型。

通用关键词始终保留。新模型名称不需要先加入仓库才有资格收录。

## 接入外部数据源

获取平台允许使用的 API、作者导出或公开页面中的作品链接，转为每行一个对象的 JSONL。导入字段在 [快速开始](QUICKSTART.md) 列出。适配器应输出来源原链接，保留作者署名；不得把自动摘要作为作者 Prompt。

不同平台的登录要求、可用接口和搜索覆盖会变化，因此没有宣称可长期通用的全网爬虫。读取失败时保留线索和失败原因，之后可人工补充；不要绕过登录、付费或访问限制。

## 核验顺序

1. 找到创作者原帖或作者再次发表的页面，确认作品使用 AI 视频工具。
2. 找到对应 Prompt，辨别是全文、局部镜头、参考图 Prompt 还是整理者猜测。
3. 记录模型及版本的直接依据，参考图、视频、音频、后期步骤缺失时明确说明。
4. 将页面可读、视频可播、来源可信、实际复现分别记录。
5. 核验通过后更新 JSON，生成页面并在 PR 中审阅。

## 后续扩展

下一阶段可增加获准平台接口适配器、搜索结果导出和辅助提取；这些输出仍进入候选队列。定时任务、付费 API、媒体备份和自动发布均未配置。先评估每个平台的实际可读率，再决定投入哪种采集方式。
